# अवध Chai Khana (Awadh Chai Khana) - The First Tea House on Mars 🪐

An authentic, culturally rich web experience for the Solar System's first Awadhi tea house on the Red Planet (Olympus Mons Base, Valles Marineris, Jezero Crater). Built with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## ☕ The Red Planet Concept

1. **Exact Same Earth Recipes, On Mars**:
   - *Nawabi Zafrani Kulhad Chai* (Saffron & Cardamom in solar-kiln fired Martian red regolith clay)
   - *Hazratganj Kadak Dum Chai* (Robust ginger-clove slow-simmered tea in 1.0 ATM pressurized samovars)
   - *Kashmiri Noon Chai / Gulabi Chai* (Pink salted tea whisked with rich cream for -60°C Martian nights)
   - *Makhan Malai Bun Maska*, *Khasta Kachori*, and *Shahi Tukda Rabri Bites*.

2. **0.38g Low Gravity & Regolith Pottery**:
   - Pottery crafted using mineral-rich iron soil from Jezero Crater, releasing the fragrance of rain (*sondhi khushboo*) on an arid world.
   - Weighted bases designed for low-gravity sipping.

3. **3 Martian Domes**:
   - **Olympus Mons Summit Dome (HQ)**: Highest tea stall in the Solar System (21.9 km elevation).
   - **Valles Marineris Canyon Kiosk**: Deep canyon chasma promenade.
   - **Jezero Crater Biosphere Lounge**: Botanical garden seating near the Perseverance Memorial.

4. **Features**:
   - Interactive Chai Customizer (अपनी चाय) with planetary options.
   - Colony Token Order Checkout.
   - Sol Baithak Table Reservations.
